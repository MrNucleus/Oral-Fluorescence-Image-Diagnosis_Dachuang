# 技术方案
 
## 项目概述
 
基于深度学习的口腔荧光图像病变**检测**。原始数据为北京大学口腔医院提供的
临床自发荧光图像，标注为 PASCAL VOC 格式（边界框 + 类别）。
 
## 数据方案
 
- 数据来源：北京大学口腔医院（临床自发荧光图像）
- 原始格式：`.JPG` 图像 + `.xml` 标注（VOC）
- 类别：`l`、`n`（临床含义待与标注方最终确认）
- 样本组织：按患者文件夹存放，每个患者含多张图（部分有标注，部分无标注）
- **划分策略**：按**患者**划分 train/val/test（约 7:1.5:1.5），
  防止同一患者图片跨子集导致数据泄露
- **背景样本**：无标注图片作为背景样本纳入训练（空标签）
- 预处理：待补充（光电队员负责，聚焦荧光图像的光照/色彩特性）
 
## 模型方案
 
- 基线：**YOLOv8**（`yolov8n.pt` 起步，逐步升级到 `s/m`）
- 框架：ultralytics
- 训练策略：迁移学习（ImageNet/COCO 预训练）+ 余弦退火 + 早停
- 数据增强：Mosaic / MixUp / 随机翻转 / 色彩抖动（YOLO 内置）
 
## 评估方案
 
- 指标：**mAP@50、mAP@50-95、Precision、Recall**
- 可视化：PR 曲线、混淆矩阵（ultralytics 自动生成）
- 可解释性：Grad-CAM 类方法（后续集成）
 
## 代码结构
 
| 模块 | 文件 | 职责 |
|------|------|------|
| 解析 | `src/data/voc.py` | 解析 VOC XML，转 YOLO 标签 |
| 构建 | `src/data/build_dataset.py` | 患者级划分 + 生成 YOLO 数据集 |
| 探索 | `src/data/analyze.py` | 数据统计与 EDA |
| 训练 | `src/train/yolo_train.py` | 封装 ultralytics 训练 |
| 评估 | `src/eval/yolo_eval.py` | 计算并保存指标 |
| 推理 | `src/infer/predict.py` | 单图/批量预测 |
