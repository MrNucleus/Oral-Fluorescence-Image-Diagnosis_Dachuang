# 技术方案

## 项目概述
基于深度学习的口腔荧光图像辅助诊断。

## 数据方案
- 数据来源：北京大学口腔医院
- 类别数：5（Normal, OLK, OLP, OSCC, Other）
- 数据划分：7:2:1
- 预处理策略：

## 模型方案
- 基线模型：ResNet-50 / EfficientNet-B0
- 注意力机制：CBAM / SE
- 训练策略：迁移学习 + 余弦退火 + Early Stopping
- 损失函数：CrossEntropy / Focal Loss

## 评估方案
- 指标：Accuracy, F1-Macro, AUC-ROC
- 可视化：混淆矩阵, ROC曲线, Grad-CAM
