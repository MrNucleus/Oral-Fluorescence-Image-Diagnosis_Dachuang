## 一、答辩应该讲清楚什么

项目当前主线是：面向口腔白光与自体荧光图像，建立保留完整视野的图像级候选二分类流程，通过预训练卷积网络、受控模型比较和训练重复，筛选后续优化模型。当前完成数据接入、基线、八组架构/注意力/损失筛选及基线与SE的三种子复验；ResNet50+SE+CE为优先候选，最终模型尚未冻结。

## 三、模型构建思路：从研究问题到实现

### 1. 先固定任务与输出

输入是一张完整RGB口腔图像，包含standard（白光）或fluorescence（荧光）模态；输出是两个候选类别的概率，其中0为normal_candidate、1为lesion_candidate。阳性候选概率达到0.5时输出病变候选。

当前是两类图像共同进入同一个单图分类网络；每次只输入一张图，不能描述成白光—荧光双分支配对融合模型。模态信息用于数据组织和后续分层分析，当前网络没有模态嵌入或跨模态融合头。

选择整图任务的实际实现约束是保留完整视野、不用XML框训练、不裁ROI。这使当前输出对应整幅图像的候选类别；病灶定位、分割以及病理分型不在当前已实现输出内。历史YOLO检测路线应作为早期探索介绍，评价指标mAP不适用于当前分类主线。若需要解释路线调整的具体决策时间和导师意见，必须补真实记录。

### 2. 固定数据，避免实验之间换口径

| 划分 | 图像数 | 正常候选 | 病变候选 | 来源组数 |
|---|---:|---:|---:|---:|
| 训练 | 893 | 332 | 561 | 235 |
| 验证 | 112 | 43 | 69 | 16 |
| 测试 | 112 | 43 | 69 | 17 |
| 合计 | 1117 | 418 | 699 | 268 |

当前使用v7整图交接包，入口为dataset.json。源码校验任务类型、类别映射、图像清单、哈希和来源组是否跨划分。来源组隔离降低同组图像跨集合的风险，但来源组尚未核验为独立患者，不能把268组写成268名患者，也不能据此保证不存在患者级泄漏。

标签是候选标签，尚不能直接解释为健康、癌前病变或口腔癌的临床确诊。XML虽随数据交付，但没有参与当前分类目标或ROI提取；后续可在核验后用于解释审核。

### 3. 保留视野，同时控制输入成本

训练采用640×640输入，通过等比缩放与灰色补边保持长宽比及完整视野；补边颜色为RGB(114,114,114)。几何增强包括概率0.5的水平翻转、概率0.5的±10°随机旋转；旋转扩展画布，避免直接裁掉旋转后的边缘，再等比缩放补边。输入使用ImageNet归一化。

当前正式训练采用geometry增强；代码支持模态相关亮度策略，不代表正式实验启用了它。平场校正、降噪、高光抑制和专门色彩校正也不能作为已完成的独立预处理成果。

缓存v1中，训练图先按最长边640缩小并保存uint8缓存，再执行在线增强与最终补边、归一化；验证缓存保存确定性输入。训练的变换顺序相较旧原图流程发生变化，因此缓存训练作为独立预处理版本重新训练。验证输入已有逐元素一致性检查，不能将其扩大解释为新旧训练过程完全等价。

保留整图不等于保留原始分辨率的全部细节。缩小到640可能影响微小病灶特征，后续应结合错误案例评估；当前未完成分辨率消融。

### 4. 先建立可解释的迁移学习基线

基线使用torchvision的ImageNet预训练ResNet50，将原分类头替换为两类线性层。代码未设置冻结主干，主干与新分类头共同训练。

结构可以画为：

```text
完整RGB图像 → 缓存v1/几何增强/等比补边/归一化
           → [B,3,640,640]
           → ResNet50卷积主干（stem → layer1 → layer2 → layer3 → layer4）
           → 全局平均池化 → 2048维特征 → Linear(2048,2)
           → 两类logits → Softmax → 病变候选概率 → 阈值0.5
```

迁移学习的动机是利用已有视觉表示，在当前有限数据上训练任务相关特征；这是选型理由，并非本项目已经通过“随机初始化对照”证明的结论。ResNet18属于此前基线阶段，当前正式受控比较以ResNet50为对照。

### 5. 用三个问题组织八组比较

第一问：更换特征提取架构是否改善？比较ResNet50、EfficientNet-B3、DenseNet121，均不加额外注意力、使用CE。该比较是在相同输入大小、训练预算和优化设置下的工程筛选；并未为每个架构分别完成最优超参数搜索。

第二问：在ResNet50不变时，增加特征注意力是否改善？比较none、SE、CBAM。这样可以把注意力接入与整套主干替换区分开。

第三问：在ResNet50且不加额外注意力时，改变训练损失是否改善？比较CE、weighted CE、label smoothing、Focal。当前不是架构×注意力×损失的完整因子实验，没有验证SE+Focal的组合效应或交互作用。

### 6. SE到底如何接入

当前在ResNet50的layer4整体输出后、主干原有全局池化之前，接入一个通道注意力模块。它没有插入每一个残差块，答辩结构图应与此一致。对640输入，按该标准主干结构推导，特征约为[B,2048,20,20]；这是结构尺寸推导，不是本次新增的实测张量记录。

对特征F的每个通道做空间平均，得到通道描述z；通过2048→128→2048的两个1×1卷积及中间ReLU，最后用Sigmoid生成0至1的通道权重s，再逐通道乘回F：

`z_c = mean(F_c)`；`s = sigmoid(W2 · ReLU(W1 · z))`；`F'_c = s_c · F_c`。

随后进入全局平均池化和两类分类头。该设计尝试让模型自适应调节不同特征通道的贡献；权重本身不是临床标志物，也不能直接证明模型关注了病灶。

CBAM对照在同一位置先做通道注意力（平均池化与最大池化共享MLP），再以通道平均/最大响应拼接后经7×7卷积做空间注意力。结构更复杂并不保证更适合当前数据，需看实际验证结果。

### 7. 损失函数分别解决什么问题

| 损失 | 当前实现 | 研究动机与解释边界 |
|---|---|---|
| CE | 标准两类交叉熵，`-log(p_y)` | 建立统一基线 |
| weighted CE | 训练集类别权重`N/(2*n_c)` | 检查类别不平衡处理；不使用验证或测试标签估计权重 |
| label smoothing | 平滑系数0.1 | 尝试缓解过度自信；本次不能据此宣称概率已校准 |
| Focal | gamma=2，`(1-p_y)^2 * CE`，无额外alpha项 | 降低易分类样本的相对贡献；尚未与SE组合比较 |

不论训练损失选择哪一种，选检查点统一使用整体验证集无权重、无平滑CE，以避免直接比较数值含义不同的训练损失。

### 8. 固定训练与选模规则

当前正式系列共同采用：640输入、batch4、workers0、AdamW、初始学习率0.001、weight decay 0.0001、FP32、最多100轮、patience20。seed42用于八组筛选，seed43/44用于基线与SE复验；各次从预训练初始化重新训练，不从seed42最优检查点继续训练。

训练集用于参数更新，验证集用于检查点选择和方案比较。选择最低验证CE轮，所有辅助指标也来自该轮；不能改用AUROC最高的另一轮拼接报告。保存best.pt、last.pt、逐轮历史、配置与恢复状态，使结果能够追溯。

阈值固定0.5。AUROC描述概率排序能力；敏感度为TP/(TP+FN)，特异度为TN/(TN+FP)，平衡准确率为二者均值。准确率需要结合类别比例理解，不单独作为成功标准。

## 四、答辩核心结果页

### 1. 八组seed42正式筛选：均为验证结果

| 模型 | 注意力 | 损失 | 验证CE↓ | AUROC↑ | 平衡准确率↑ |
|---|---|---|---:|---:|---:|
| ResNet50 | none | CE | 0.4904 | 0.8022 | 0.7199 |
| EfficientNet-B3 | none | CE | 0.3915 | 0.8982 | 0.7167 |
| DenseNet121 | none | CE | 0.5426 | 0.7907 | 0.7083 |
| ResNet50 | SE | CE | 0.3362 | 0.9447 | 0.8694 |
| ResNet50 | CBAM | CE | 0.4199 | 0.8655 | 0.7954 |
| ResNet50 | none | weighted CE | 0.6429 | 0.5470 | 0.5000 |
| ResNet50 | none | label smoothing | 0.4147 | 0.8881 | 0.7720 |
| ResNet50 | none | Focal | 0.4116 | 0.9012 | 0.8650 |

SE在本次筛选中验证CE最低，因此进入复验。weighted CE按最低CE规则选中的第1轮全部预测为阳性候选，应保留这一失败结果，不能推断其所有训练轮均如此。Focal的平衡准确率接近SE，但按预定CE规则本轮优先选择SE；不能由此推出两者组合必然更好。

### 2. 三种子复验：主结果建议使用这一页

| 指标 | ResNet50基线 | ResNet50+SE |
|---|---:|---:|
| 验证CE | 0.4489±0.0391 | 0.3731±0.0381 |
| 验证AUROC | 0.8500±0.0434 | 0.9138±0.0292 |
| 验证平衡准确率 | 0.7503±0.0528 | 0.8316±0.0343 |
| 验证敏感度 | 0.7874±0.0824 | 0.8647±0.0167 |
| 验证特异度 | 0.7132±0.0748 | 0.7984±0.0817 |

以上为3个训练种子的均值±样本标准差。SE的AUROC平均增加0.0638，平衡准确率平均增加8.13个百分点；三个种子均改善，但seed42改善幅度更大。标准差描述训练随机性，不是患者置信区间，也不是集成模型性能。八组方案加四次新增复验，共12次正式缓存流程训练；两份复验归档报告不是两套独立实验。

建议原话：“在固定数据、预处理及训练设置下，SE候选在三个种子上的验证指标均优于基线，因此进入下一阶段优化。该结果来自同一112张验证集，独立泛化仍待检验。”

### 3. 历史测试结果必须单列

2026-10-27旧ResNet50基线报告记载测试AUROC 0.6943、平衡准确率0.6892，说明当时验证与测试存在明显差距。其batch、预处理版本与当前缓存系列不同；不能把这组旧测试指标配到当前SE结构下，也不能将当前验证AUROC 0.9138当成测试结果。

旧报告标题下的数据版本字段写v5，而当前系列按v7交接包记录，存在命名不一致；若引用历史数据，应先按dataset.json哈希和实际配置追溯，不能只依据版本名称声称数据完全不同或完全一致。最新八组及复验报告没有新增测试推理；当前测试集曾有历史评估，后续同集评估须说明其已被查看。

## 五、贡献、问题和下一阶段

当前可陈述的工作贡献包括：建立全视野候选分类流水线；完成三类主干、两种附加注意力、四类损失的受控筛选；对优先候选补充三种子训练重复；实现版本化缓存、记录、恢复和训练看板。它们体现项目阶段工作量与工程完整性，普通SE模块本身不足以支撑独立算法创新主张。

需要主动解释的问题：验证集仅112张、16个来源组，反复筛选可能过拟合；患者关系与候选标签仍待核验；模态/部位可能带来分布差异；训练存在验证CE尖峰和后期波动。已有seed43基线第26轮验证CE9.7464、seed44基线第32轮2.2515，成因尚未诊断，不能直接归咎于学习率或BatchNorm。

下一阶段按依赖推进：

1. 排查验证损失尖峰、训练/验证模式与归一化状态，保留全部历史结果。
2. 单独开展AMP/FP32吞吐与数值稳定性短测，避免把提速与效果优化混在一起。
3. 固定SE+CE，在0.0001、0.0003、0.001三个学习率上作三种子比较；新增6次，复用相容的0.001对照。学习率入口仍待实现，不能写已开始。
4. 若学习率改变且需要归因SE收益，补充同学习率的公平基线。
5. 冻结模型、预处理、阈值、权重哈希和评价方案后，做总体/模态/部位评价、来源组相关性区间、错误分析和Grad-CAM审核。
6. 完成推理软件、模型卡和复现交付，并寻求新的独立留出数据。

来源组MIL、模态嵌入、缺失模态和质量感知聚合可作为研究拓展，但均未实现。需先核验组关系、配对关系和组标签依据；不能将同组白光/荧光自动视作同一病灶配对，也不能将图像候选标签自动转换成组级临床诊断。

常见问答：

- **为什么先做整图分类？** 当前任务要求保留完整视野并以图像级候选标签训练；先建立可复现基线，再评估局部解释。路线调整的立项对应关系需由原申报书与导师记录补齐。
- **SE是否就是创新？** SE是已有方法，本阶段贡献在于任务适配、受控验证和完整流程；后续方法创新仍需明确研究假设和独立证据。
- **为什么不用最高AUROC选轮？** 已预先统一按最低验证CE选检查点；保持规则一致，避免事后挑指标。
- **0.9447是否代表最终性能？** 它是seed42单次验证AUROC；三种子平均为0.9138±0.0292，当前SE测试性能尚未报告。
- **三次训练是否证明泛化？** 只能描述训练随机性下的一致性，同一验证集没有新增独立样本。
- **白光与荧光融合了吗？** 当前混合训练一个单图分类器，没有配对双流融合。
- **为什么不继续堆模块？** 先确认提升的重复性、异常来源与比较公平性，再按研究问题做有限扩展。
- **能否临床使用？** 当前是候选标签上的研究原型；需要临床标签核验、患者级独立性核验和新的独立验证。
