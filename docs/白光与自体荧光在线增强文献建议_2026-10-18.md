# 白光与口腔自体荧光：在线增强文献建议

适用范围：口腔普通白光照片（WLI）与宽场自体荧光 RGB 照片（AFI）的二分类、ROI 分类及目标检测。本文提供方法依据和待验证的实验方案，不是已经验证有效的训练配置；设备输出若是伪彩、比值图或其他处理图，需要另行定义通道含义。实际工作、失败、验证及交付记录统一见[项目工作记录](PROJECT_WORK_LOG.md)。

## 1. 结论与证据强度

建议两种模态共用“保留病灶的几何增强”原则，分别设置光度增强。白光可试轻微曝光和对比度变化；荧光先建立仅几何增强的基线，再单独评估三通道同步的小幅乘性增益。随机擦除、MixUp、CutMix 均不作为本项目首轮默认配置。

这里区分三种依据：

- **直接方法证据**：论文在口腔照片/双模态口腔图中实际采用了哪些增强。
- **光学与临床依据**：哪些强度、颜色比例和局部结构可能承载诊断信息。
- **工程起始建议**：为本项目提出的试验参数，尚需训练集预览、临床抽查和验证集消融；不称为指南、共识或已证实的最优参数。

本轮核验文献没有直接证明截图整套参数适用于本批设备和数据，也没有证明荧光的所有亮度/对比度调整都必然有害。

| 文献 | 核验到的方法或发现 | 对本项目的意义与边界 |
| --- | --- | --- |
| Fu 等，2020，EClinicalMedicine [1] | 普通口腔照片；采用缩放、旋转、水平翻转、饱和度及曝光调整；验证数据不执行增强；先定位疑似病灶再裁剪分类 | 支持白光几何与光度增强作为候选策略。本文核验正文，未核验补充材料中的具体幅度；不能据此引用截图的百分比，也不是荧光颜色增强的验证 |
| Song 等，2018，Biomedical Optics Express [2] | 白光与自体荧光融合；采用旋转与翻转，从一图得到八个方向版本，并比较有/无增强；融合通道为白光 R、G 与荧光归一化 R/G | 为双模态口腔图的几何增强提供直接证据。其探头图像被认为无固定自然方向，不表示本批图像应自动采用全部旋转方向；融合通道不是普通 RGB，不能直接套 RGB ColorJitter |
| Praveen Birur N. 等，2022，Scientific Reports [3] | 现场双模态系统继续融合白光 R、G 和荧光归一化 R/G；使用自适应直方图均衡等预处理及增强 | 说明需按通道物理含义设计管线。确定性图像预处理与训练时随机颜色增强是不同问题；论文不是截图各参数的消融验证，参考标准也并非全量组织病理 |
| Roblyer 等，2009，Cancer Prevention Research [4] | 在研究设备上利用荧光红绿比值及同部位正常参照归一化区分组织；讨论舌背红色荧光带来的混杂 | 荧光通道比例及局部参照可能是有效信息；不宜任意改色，也不能把红色荧光或荧光减弱直接等同恶性。论文阈值不可移植为本批图像的诊断阈值 |
| Gurushanth 等，2026，Diagnostics [5] | 定量研究发现正常口腔不同亚部位存在荧光强度差异，特别是舌侧缘/舌腹；强调采集距离、位置和设备标准化 | 支持保留模态与部位信息、按部位检查增强后的表现。属于概念验证研究，部分病变以初步临床诊断为参照；不是增强策略对照试验 |
| MixUp 原论文 [6]；CutMix 原论文 [7] | MixUp 对图像及标签作凸组合；CutMix 切贴图块并按图块面积混合标签，主要在通用视觉数据上验证 | 可解释其机制，不能直接证明适用于口腔自体荧光。小病灶的语义贡献不一定与图块面积成比例 |

特别说明：Song 2018 和 Birur 2022 确实采用了自适应直方图均衡，Song 还描述了锐化。不能据此得出“荧光永远不能调整对比度”，也不能反向推导“任意局部均衡都保留原始 R/G”。如需复现，应把它作为独立的预处理实验，记录作用通道、顺序、参数与评价结果；首轮先保留无此处理的基线。

## 3. 白光与荧光为什么需要不同的光度策略

白光图主要呈现反射光下的黏膜形态、颜色、表面纹理和血管/溃疡等结构；轻微光照差异可以来自采集过程。红色、白色和红白相间本身也有临床意义，所以白光同样不适合无限制改色或默认灰度化。

自体荧光图呈现激发后组织发射的光信号，受到内源荧光、组织吸收/散射、血液、角化、采集几何和设备处理共同影响。局部绿色荧光减弱、红绿关系及病灶与周围组织的差别可能参与识别 [2–5]。这些是需要保留的候选信号，不是可任意打乱的外观。荧光减弱并不特异于癌症，本项目逐框 `l/n` 也不能升级为组织病理诊断。

“荧光不能调亮”过于绝对。若各像素、各通道都乘以同一正系数 a，且不发生截断、量化或额外偏置，则：

```text
R' / G' = (aR) / (aG) = R / G
I'病灶 / I'参照 = (aI病灶) / (aI参照) = I病灶 / I参照
```

因此，小幅统一增益比逐通道随机增益更适合作为第一项荧光光度实验。但它仍改变绝对强度，模型未必只利用比值；JPEG 的相机处理/非线性也意味着数值比值不等于经标定的光谱比值。上述等式不是物理标定，更不保证模型预测不变。

以下操作不能与上述共同增益等同：独立 RGB 增益、白平衡变化、色相/饱和度变化、加常数偏置、gamma 变换、局部对比度增强及局部阴影。这些操作可能改变通道比例或病灶—背景关系。普通库中的“brightness”究竟是乘法还是加法也应核对实现。

## 4. 对项目书截图的逐项建议

| 截图建议 | 白光 WLI | 自体荧光 AFI |
| --- | --- | --- |
| 随机裁剪 224×224 | 改为病灶保持裁剪或整图保比例缩放/填充；避免裁掉病灶后仍沿用阳性标签 | 同样需要病灶保持，并尽量保留周围组织用于相对荧光判读 |
| 水平翻转 p=0.5 | 可作为起始项；本任务不区分左右侧类别 | 同左；几何方向变化通常比改色更容易保留信号 |
| 随机旋转 ±15° | 可试小角度，检查边缘病灶及填充伪影 | 可试小角度，同步变换检测框；不默认大透视/弹性形变 |
| 亮度 ±20% | 先缩小范围，检查红/白病变、反光和过曝 | 不直接照搬；先关闭，后单独评估小幅共同增益 |
| 对比度 ±15% | 可作小幅候选，不与多项强扰动同时堆叠 | 首轮关闭；避免局部荧光减弱被随意强化或抹平 |
| 饱和度 ±10% | 非必需；先关闭或仅极轻微试验，保留红白色彩特征 | 首轮关闭；不默认色相抖动、通道交换、随机灰度 |
| 高斯噪声 std=0.01 | 不作为首轮必需项；若后续需要，明确数值范围与噪声施加位置 | 首轮关闭；弱光噪声受光子/读出噪声和相机处理影响，任意独立高斯噪声不等于真实荧光噪声 |
| 随机擦除 p=0.3 | 首轮关闭，可能遮住决定标签的病灶 | 首轮关闭，可能遮住病灶或伪造局部荧光缺失；与当前排除遮挡框的策略也不一致 |
| MixUp α=0.2 | 首轮关闭，作为后续单独消融项 | 首轮关闭；合成荧光分布未必对应真实采集情形 |
| CutMix α=1.0 | 首轮关闭，图块面积权重未必反映病灶是否存在 | 首轮关闭，同样有标签与局部信号失配风险 |

`std=0.01` 只有明确数值域才有意义：如果图像在 [0,1] 且在标准化前加噪，约相当于 8 位图的 2.55 个灰度级；在 ImageNet 标准化后加相同数值是另一种扰动。MixUp/CutMix 的 α 是混合权重分布参数，不是执行概率，也不是“混合 20%”。

CutMix 的具体风险示例：一张阳性整图中病灶只占很小面积，如果贴片恰好移除了全部病灶，余下大面积黏膜仍可能按面积获得较高阳性软标签；反过来，贴入一个小病灶也可能只得到很低的阳性权重。这是本项目的标签保持风险分析，不是证明 CutMix 在所有医疗任务中无效。

## 5. 可交给训练同学的起始方案

下表数值是本项目的**保守工程起点**，不是文献规定。建议先不叠加太多操作；验证集决定是否保留某项。白光与荧光根据清单中的 `modality` 使用独立增强分支。

| 项目 | 白光起始配置 | 荧光起始配置 |
| --- | --- | --- |
| 输入准备 | 保持比例 resize + padding；ROI 任务从 XML/框索引确定性裁剪，再缩放 | 同左，优先保留病灶与一定周边组织 |
| 几何 | 水平翻转 p=0.5；旋转范围 ±10°、执行概率 p=0.5 | 同左 |
| 曝光/增益 | 几何基线后，单独试共同乘性增益 0.90–1.10，p=0.3 | 基线关闭；额外实验只试共同乘性增益 0.95–1.05，p=0.3 |
| 对比度 | 曝光项验证后，可单独试系数 0.90–1.10，p=0.3 | 基线关闭 |
| 饱和度 | 基线关闭；有需要时单独试系数 0.95–1.05，p=0.2 | 关闭 |
| 色相、随机白平衡、通道独立增益 | 关闭 | 关闭 |
| 噪声、模糊、擦除、MixUp、CutMix、Mosaic | 首轮均关闭 | 首轮均关闭 |

固定的模型输入标准化（例如明确的预训练模型规范）与随机光度增强不同。采用前者时需固定并记录；自行估计的数据均值/方差只从 train 拟合。不要为消除部位差异而擅自把每张荧光图的亮度或直方图拉成一样。

224×224 是模型输入规格的候选值，不代表应从原图任意截取一个 224×224 小块。整图缩到 224 后，小病灶可能只剩少量像素，应查看缩放后的目标尺寸；输入分辨率、ROI 方案与模型任务需要一起确定。整图模型与 ROI 模型的应用场景不同：训练和测试均使用真实人工框裁剪时，评估的是“已给出区域”的分类性能；部署需自动定位时还应评估定位误差，不能把前者直接当作整图自动筛查性能 [1]。

ROI 可先试四周保留约 20%–30% 的上下文，但这是既有项目建议和待验证起点，不是通用临床阈值。边界外组织不能自动视为正常参照，多个框的邻近区域也可能包含病变。

检测任务的旋转、翻转、缩放、裁剪要同步变换所有保留框；不能把分类用的 MixUp/CutMix 软标签逻辑直接套到检测框。首轮优先不截断标注目标；若允许部分目标，应事先定义可见比例和框过滤规则，记录因此丢弃的目标。相交框本身允许保留。

若以后训练真正配准的白光—荧光双输入模型，空间变换需要同步，光度分支仍分别设置；必须先有逐图配对/配准证据，不能仅凭同一来源文件夹认定两图配准。首轮不做白光与荧光之间的像素级 MixUp/CutMix；同一模态内的跨图增强也只可使用 train。

## 6. 最省时间、可解释的验证顺序

沿用已经冻结的来源文件夹级 8:1:1 split，增强版本不改变 split；同一原图的整图输入、多个 ROI 及增强视图必须继承同一 split。该划分口径不能被表述为已证明患者级独立，特别是同一人不同部位被分开时。

1. **A：无随机增强**。两种模态只做固定 resize/padding/normalize，得到可比较基线。
2. **B：仅几何增强**。两模态分别比较 A 与 B。
3. **C：按模态增加一项光度增强**。白光先试曝光；荧光只试共同增益。白光对比度/饱和度若有必要，再逐项加入。

可以用同一模型和 `modality` 分支实施，也可以做单模态基线；无论采用哪种形式，至少分模态报告指标，不能只汇报混合总体准确率。部位用于已有来源字段支持的分层报告，不新增照片解剖推断，不为此训练多个部位模型。每个消融实验保持模型、训练预算和 split 一致，尽可能使用相同种子组；时间允许再重复多个种子。

在验证集比较 AUROC、灵敏度、特异度、F1，并给出两种模态及可评估部位的样本数。阈值和增强选择在验证集完成，测试集留到最终方案冻结后评价。小样本差异需要考虑不确定性；若有置信区间，重采样应尊重来源分组，不把同组图片当完全独立样本。

正式长训练前，数据管理员与临床同学应在训练集随机抽样查看多个增强结果：病灶是否完整、颜色或荧光缺失模式是否明显改变、是否产生过曝/黑块/复制病灶、框是否同步。不把此检查说成疾病确诊或完整自然遮挡审计；检查记录放到统一工作记录，需要保留的逐图证据只放私密目录。

在线增强配置应记录操作顺序、范围、概率、随机种子、库版本、插值和填充值、通道含义、输入数值域及截断处理。在线增强增加的是同一来源的训练视图，不增加独立患者/病例数。配置只在 train 使用，val/test 采用固定预处理。

本方法说明作为现有 v5 简略增强说明的补充：旧说明中“只在 train 内使用 Mosaic/MixUp”规定的是防泄漏边界，不代表本项目已验证其有效或建议默认开启。本建议首轮关闭这些操作；后续采用时由训练配置版本和消融证据说明。

## 7. 仍需补齐的采集信息

优先向采集方核实设备型号、荧光激发波段与滤光片、图片是否经过伪彩/比值/自动均衡、曝光和白平衡是否锁定。上述文献中常用约 405 nm 激发，不足以确认本批数据的实际设备参数。信息未补齐前，荧光仅几何的基线仍可推进；信号模拟和较强光度增强应暂缓。

## 8. 可用于修改项目书的方法表述

> 根据普通白光与自体荧光成像机制建立独立的在线增强分支。两种模态均采用保留标注目标及周围组织的几何变换；白光图像评估小幅曝光与对比度扰动，自体荧光图像优先保留通道比例和局部荧光分布，在几何基线基础上单独评估共同乘性增益。首轮不默认采用随机擦除、MixUp 和 CutMix。所有随机增强仅作用于训练集，检测框与空间变换同步，通过验证集消融确定最终策略，测试集使用固定预处理。
