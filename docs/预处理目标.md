# 荧光图像预处理：目标与验收标准

> 负责人：光电专业队员
> 关联代码：`src/data/preprocessing.py`（待创建）
> 关联文献：Yang 2019（多模态光学系统）、Cherry 2019（AFI 定量分析）

## 1 总目标

让不同患者、不同拍摄条件下的荧光图像，处理后具有**一致的亮度与色彩表现**，
使模型学到的是**病变特征**，而不是**拍摄条件差异**。

一句话：输入 590 张原始荧光图 → 输出**亮度均匀、色彩一致、无高光干扰**的干净图像，
并用「处理前 vs 处理后」的训练结果（mAP 差值）证明预处理有效。

## 2 待解决的具体问题

| # | 问题 | 光学原因 |
|---|------|---------|
| 1 | 图像中心亮、边缘暗 | 激发光强度分布不均 |
| 2 | 不同图像色彩表现不一致 | 设备伪彩色映射差异 |
| 3 | 黏膜表面出现亮斑 | 镜面反射 / 唾液反光 |
| 4 | 低荧光区域颗粒感重 | 传感器噪声 |
| 5 | 病灶与正常组织对比不足 | 自发荧光对比度低 |
| 6 | 部分图模糊 / 过曝 / 欠曝 | 拍摄质量参差 |

## 3 处理方法与目标结果

| # | 处理方法 | 目标结果 | 定量指标 |
|---|---------|---------|---------|
| 1 | 平场校正（flat-field） | 整幅图亮度均匀 | 亮度标准差 ↓ |
| 2 | 色彩空间校正 | 色彩表现统一 | 通道均值方差趋同 |
| 3 | 高光检测与抑制 | 镜面高光被压掉 | 高光像素占比 ↓ |
| 4 | 降噪 | 信噪比提升 | SNR ↑ |
| 5 | 对比度增强（RG 比值类） | 病灶更突出 | 类间对比度 ↑ |
| 6 | 质量筛查 | 标记 / 剔除废图 | 废图清单 |

## 5 验收标准

### 5.1 定性（最低要求）
- 处理前后并排对比，肉眼可见改善（亮度更均匀、高光消失）

### 5.2 定量（进阶）
- 亮度标准差下降、信噪比提升、对比度提升，并记录具体数值

### 5.3 下游验证（关键，决定预处理是否有价值）
- 用处理后的数据训练，**mAP 相比未处理有提升**

> 前两条只是过程指标，**下游验证才是真正结论**。

## 6 检查方法（具体怎么做）

| 检查项 | 计算方法 | 产出 |
|--------|---------|------|
| 亮度均匀性 | 灰度图分块求标准差 | 数值 + 亮度热力图 |
| 对比度 | RMS 对比度或 Michelson 对比度 | 数值 |
| 信噪比 | 背景区均值 / 背景区标准差 | 数值 |
| 高光比例 | 高亮阈值以上像素占比 | 数值 |
| 视觉效果 | 处理前后并排、统一显示范围 | 对比图 PNG |

建议：每类随机抽 5 张，做「原图 | 处理后 | 差值图」三联图，放进 `notebooks/`。

### 预处理函数建议清单

```python
def correct_illumination(image): ...   # 平场校正，解决亮度梯度
def correct_color(image): ...          # 色彩空间校正
def suppress_specular(image): ...      # 镜面高光抑制
def denoise(image): ...                # 降噪
def enhance_contrast(image): ...       # 荧光对比度增强
def quality_score(image): ...          # 质量评分（模糊/过曝/欠曝）
```

每个函数需在文档字符串中说明：**处理的是什么光学现象、为什么这样做**，
