## 摘要

本项目下一阶段不宜继续沿用“YOLO 病灶检测”或“继续更换分类骨干网络”的单一思路。新数据包已经具备双模态、来源组、多图、部位和历史 XML 等信息，但也存在候选标签未经临床确诊、来源组不能等同于独立患者、同一来源组的不同模态没有确认逐图配对等限制。因此，最有辨识度、也最符合真实临床工作流的创新方向是：

> 构建面向双模态口腔图像的可信候选筛查框架，以来源组为决策单位，处理多图、缺失模态、图像质量差异和不确定病例，并在总体、模态、部位及解释层面进行统一评价。

推荐将以下四项组成论文主创新：

1. 组级多示例学习，把同一来源组的多张图片作为一个 bag，只使用来源组候选标签，让模型学习哪些图片支持阳性判断。
2. 缺失模态适应，使同一模型能够处理白光、荧光或双模态输入，而不是假设每次检查都具备完整模态。
3. 质量感知与可弃权预测，在低质量或不确定时拒绝自动判断，并报告风险覆盖率。
4. 部位分层与解释定位审计，在冻结测试预测后统一报告各部位表现，并仅使用历史 XML 检验显著性图定位，不把 XML 框作为训练目标。

无配对跨模态对比学习、物理感知预处理、主动标签复核和共形预测作为加分模块，应在基础模型存在可重复信号后再逐项加入。

### 1.2 尚不能确认的事项

- 候选标签不等于医生确诊、组织病理诊断或具体疾病类型。
- 268 个来源组不等于 268 位已确认的独立患者。
- 同一来源组同时具有两种模态，不等于两张图片来自同一病灶、同一时刻或同一采集位置。
- 历史 XML 可用于证据审查和解释评价，但当前不得作为整图模型的训练目标。
- 旧模型结果不能直接外推到 v7 新数据。
- 当前尚未完成系统查新，不能使用“国内外首次”或“首创”等表述。

### 1.3 对项目阶段的判断

当前已跨过“能否建立数据与训练管线”的阶段，进入“能否把技术流程转化为有科学价值的问题”的阶段。旧数据的绝对性能较弱，因此以高准确率为唯一目标风险较高。更可行的路径是把研究问题从“模型能否诊断”改写为：

- 在什么输入条件下，模型能够提供有价值的候选筛查；
- 模型在哪个模态、部位和质量区间更可靠；
- 模型何时应当弃权；
- 多图和多模态信息是否真的优于单图、单模态；
- 模型的解释是否与历史病灶位置一致。

这些问题不依赖虚构的金标准，却可以通过冻结数据、预设实验和消融得到可检验结论。

## 2. 创新性的定义与边界

本报告中的创新性分为四类：

| 类型 | 含义 | 本项目的可能贡献 |
|---|---|---|
| 问题创新 | 重新定义数据所支持的研究问题 | 从单图诊断改为组级、多模态、可弃权候选筛查 |
| 方法创新 | 提出针对数据结构的新学习或推理机制 | 组级多示例学习、无配对跨模态对齐、缺失模态适应 |
| 评价创新 | 建立更贴近临床使用的验证和报告方式 | 部位分层、校准、风险覆盖率、XML 解释审计 |
| 数据创新 | 形成可复现的数据视图、基准和失效图谱 | v7 冻结基准、质量分层、错误分类体系 |

一个方向要进入主论文，至少应满足以下条件：

1. 与当前数据特性直接相关，而不是可无差别套用到任何图像分类任务。
2. 有明确、可预先定义的主要终点。
3. 在固定训练预算下完成公平消融。
4. 改进在多个随机种子或训练集内部组级交叉验证中方向一致。
5. 不依赖测试集调参，不把候选标签升级为临床诊断。
6. 结果失败时仍能提供有意义的阴性结论或方法学发现。

## 3. 总体创新定位

### 3.1 推荐论文主线

暂定题目：

> 面向双模态口腔图像的可信候选筛查：组级多示例学习、缺失模态适应与可弃权预测

英文候选题目：

> Reliability-aware dual-modality oral image screening with group-level multiple-instance learning and selective prediction

该主线的核心不是提出一个全新的卷积模块，而是针对真实数据结构改变三件事：

1. **决策单位改变**：从单张图片判断改为来源组级综合判断。
2. **输入假设改变**：从固定双模态输入改为允许白光、荧光或缺模态。
3. **输出目标改变**：从强制二分类改为带置信度、校准和弃权选项的候选筛查。

### 3.2 最低可发表单元

建议先完成以下最小组合：

1. v7 冻结数据上的 ResNet-50 与 EfficientNet-B3 基线。
2. 图像级聚合、均值池化、最大池化和注意力池化的组级比较。
3. 双模态、仅白光、仅荧光和随机缺失模态比较。
4. 固定覆盖率下的敏感度、特异度、校准和弃权比例。
5. 总体、模态、部位三类分层报告。

如果这一组合能够形成稳定结果，即使绝对 AUROC 不高，也可以构成一篇“可靠性优先”的临床辅助筛查论文。

## 5. 推荐的主创新架构

### 5.1 输入层

- 输入完整 RGB 图像，保持比例缩放并补边。
- 不在主实验中随机裁剪、中心裁剪或裁 XML 框。
- 训练增强只用于训练集。
- 验证和测试使用确定性预处理。
- 保留 `image_id`、`group_id`、`split`、`modality` 和部位字段作为联表依据。

### 5.2 图像表征层

- 使用一个共享编码器作为主模型，ResNet-50 和 EfficientNet-B3 为基线候选。
- 加入模态嵌入或模态条件归一化，使模型知道当前输入来自白光还是荧光。
- 可选加入质量分支，预测清晰度、曝光、高光比例等图像质量描述。
- 可选加入物理特征分支，但必须与纯深度模型进行公平消融。

### 5.3 组级聚合层

对同一 `group_id` 下的多张图片执行：

1. 得到每张图片的病变候选概率和特征。
2. 根据模态、质量和图像数量生成注意力权重。
3. 聚合为来源组级概率。
4. 同时输出组级不确定性。

比较以下聚合方式：

- 图像概率均值。
- 图像概率最大值。
- 按质量加权均值。
- 模态分层注意力池化。
- 带不确定性惩罚的注意力池化。

这里的组级结果只能称为“来源组级结果”，不能称为“患者级结果”，除非患者关系已经核实。

### 5.4 缺失模态适应层

训练阶段：

- 双模态完整输入。
- 随机丢弃白光。
- 随机丢弃荧光。
- 单模态输入。
- 组内图片随机子采样，模拟不同检查包含图片数不同。

评价阶段：

- 完整双模态。
- 仅白光。
- 仅荧光。
- 随机缺失一种模态。

主要观察指标是不同模态可用性下的组级 AUROC、敏感度、特异度和校准差距。

### 5.5 可弃权输出层

预设两类不确定来源：

- 数据不确定性：图像质量低、曝光异常、高光比例过高。
- 模型不确定性：预测概率接近阈值、不同模态预测冲突、同一来源组内图片分歧。

输出三种状态：

- 正常候选。
- 病变候选。
- 建议人工复核。

主要报告：

- 风险覆盖率曲线。
- 固定覆盖率下的敏感度、特异度。
- 弃权比例。
- 弃权样本的质量和部位分布。

### 5.6 评价与解释层

- 总体、白光、荧光、各部位分别报告。
- 使用来源组聚类重采样计算不确定性。
- 报告 AUROC、敏感度、特异度、平衡准确率、混淆矩阵、Brier score 和校准曲线。
- 使用冻结测试预测计算 XML 框命中率和框内外能量比。
- 对解释结果只评价定位一致性，不把热力图解释为病理机制证明。

## 6. 研究问题与可检验假设

| 编号 | 研究问题 | 可检验假设 |
|---|---|---|
| RQ1 | 来源组级聚合是否优于单图独立判断 | 注意力组级聚合在组级 AUROC 和校准上优于图像概率均值 |
| RQ2 | 双模态是否优于单模态 | 完整双模态在至少一个主要亚组中优于仅白光或仅荧光 |
| RQ3 | 缺失模态训练能否提高单模态部署稳定性 | 模态 dropout 后，单模态与双模态的性能差距缩小 |
| RQ4 | 无配对跨模态对齐是否有效 | 组级对比约束改善单模态和缺失模态条件，而不降低完整双模态表现 |
| RQ5 | 可弃权预测是否改善高置信预测的可靠性 | 相同覆盖率下，弃权策略提高敏感度或降低校准误差 |
| RQ6 | 模型表现是否受部位影响 | 部位间存在可重复的性能和校准差异，模型对低样本部位不应宣称有效 |
| RQ7 | 显著性图是否与历史病灶区域一致 | Grad-CAM 命中率高于随机区域基线 |

上述假设只是研究设计中的预测，不是当前已经得到的结果。

## 7. 实验设计

### 7.1 数据与划分

- 使用 v7 冻结数据，不重新随机划分。
- 保留 893/112/112 训练、验证、测试。
- 保持 268 个来源组不跨 split。
- 测试集只在协议、模型、阈值和弃权规则冻结后使用一次。
- 在训练集内部进行按来源组的重复交叉验证，用于评估稳定性。
- 验证集用于模型选择、超参数、校准和弃权阈值选择。

### 7.2 基线

最低基线：

1. ResNet-50 整图分类。
2. EfficientNet-B3 整图分类。
3. 仅模态和部位的元数据捷径基线。
4. 颜色与纹理手工特征基线。

推荐新增：

1. ResNet-50 加模态条件归一化。
2. EfficientNet-B3 加模态 dropout。
3. 冻结自监督表征后的线性探针。

### 7.3 主实验

| 实验 | 目的 | 主要比较 |
|---|---|---|
| EXP-01 | 建立新数据单图基线 | ResNet-50、EfficientNet-B3 |
| EXP-02 | 验证组级聚合 | 单图、均值、最大值、注意力 |
| EXP-03 | 验证缺失模态 | 双模态、单模态、模态 dropout |
| EXP-04 | 验证跨模态对齐 | 普通训练、组级对比、对抗不变 |
| EXP-05 | 验证质量与弃权 | 固定阈值、质量门控、风险覆盖率 |
| EXP-06 | 验证解释一致性 | 随机区域基线、Grad-CAM、其他显著性方法 |

### 7.4 消融顺序

消融必须按依赖顺序推进：

1. 先确认单图模型是否存在可学习信号。
2. 再确认组级聚合是否带来增益。
3. 再加入缺失模态训练。
4. 再加入跨模态对齐或蒸馏。
5. 最后加入物理预处理和质量门控。

如果第一步失败，不应继续堆叠后续模块。后续结果最多只能说明某些后处理改善了随机或弱信号模型。

### 7.5 统计与报告

- 重复训练至少使用多个预设随机种子。
- 训练集内部使用按来源组的重复交叉验证。
- 测试集仅冻结后评价一次。
- 置信区间按来源组聚类重采样。
- 所有主要指标和分层结果预先列出。
- 零样本组和单类别组的指标使用 `NA` 并注明原因。
- 不依据测试子组表现修改模型或阈值。

## 8. 预期创新贡献

### 8.1 问题贡献

将单一图像分类问题重构为来源组级、多图、多模态、可弃权的候选筛查问题，更接近实际检查流程。

### 8.2 方法贡献

- 组级多示例学习与模态感知注意力聚合。
- 不依赖同病灶配对的跨模态一致性学习。
- 缺失模态训练和规则化弃权。
- 将图像质量作为模型可靠性输入，而不是简单预处理。

### 8.3 评价贡献

- 同一冻结预测上的总体、模态、部位分层。
- 风险覆盖率与校准报告。
- XML 仅用于解释定位审计，避免把历史框泄漏进训练。
- 来源组聚类的不确定性估计。

### 8.4 数据贡献

- 形成 v7 数据的可复现实验基准。
- 形成质量、模态、部位和错误类型的失效图谱。
- 记录哪些失败来自图像质量、标签不确定、模态缺失或模型结构。

## 9. 论文层面的三种选择

### 方案 A：稳健临床评价型

题目方向：

> 双模态口腔图像候选筛查的组级可靠性与失效分析

适合在基线性能中等时采用。核心贡献是组级评价、模态差异、部位差异、校准和弃权，不强行宣传高准确率。

### 方案 B：方法创新型

题目方向：

> 面向缺失模态口腔图像的可信组级候选筛查

核心模块：

- 组级多示例学习。
- 模态 dropout。
- 跨模态对比或蒸馏。
- 质量感知弃权。

适合组级基线达到可接受水平，且方法消融有一致增益时采用。

### 方案 C：物理成像创新型

题目方向：

> 物理感知预处理与质量分层在口腔双模态图像筛查中的作用

核心模块：

- 平场校正。
- 高光抑制。
- 荧光信噪比。
- 物理仿真增强。
- 质量分层评价。

适合光电成员能够提供稳定物理指标并在验证集上证明增益时采用。

## 11. 内部决策规则

以下规则用于项目管理，不是学术界的通用有效性阈值。

- 如果组级 AUROC 长期低于约 0.65，且不同种子和组级交叉验证不稳定，暂停复杂模型开发，转向标签复核、数据质量和成像物理研究。
- 如果组级 AUROC 约在 0.65 至 0.75，优先完成校准、弃权、模态和部位分层，形成可靠性评价型论文。
- 如果组级 AUROC 稳定高于约 0.75，且方法消融有一致增益，可以推进方法创新型论文。
- 如果复杂方法只在测试集表现好、验证集和组级交叉验证无一致趋势，不认定其为主贡献。
- 如果预处理或跨模态模块没有稳定增益，保留为阴性消融结果，不删除、不改写。

## 12. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 候选标签并非医生确诊 | 不能写诊断性能 | 全文限定为候选筛查；争取医生复核子集 |
| 来源组不等同患者 | 不能写患者独立评价 | 使用来源组聚类区间；推进患者关系核实 |
| 测试集仅 112 张 | 估计不稳定 | 报告来源组数和区间；不用单次点估计作强结论 |
| 部分部位样本小 | 分层结果不可靠 | 只描述，不用测试调方案，缺失指标标 NA |
| 双模态未确认配对 | 不能做早期融合和同病灶对齐 | 使用组级对齐；先声明非配对假设 |
| 图像质量差异大 | 模型学习采集捷径 | 捷径基线、质量分层、模态 dropout、可弃权 |
| 测试集可能被反复查看 | 最终评价失真 | 冻结协议、一次测试、记录所有偏离 |
| 物理预处理可能删除信号 | 反而降低性能 | 在验证集比较，保留原始图像主基线 |
| 创新方向过多 | 资源分散 | 只推进 P0 主骨架，P1 逐项加入 |

## 15. 结论

本项目最可防守的创新不是单个网络结构，而是围绕真实数据结构建立一套更可靠的研究问题、学习机制和评价体系。推荐优先完成以下闭环：

1. 在 v7 固定数据上建立单图和组级基线。
2. 证明组级聚合、缺失模态适应和可弃权预测是否带来稳定增益。
3. 在冻结测试集上统一报告总体、模态、部位、校准和解释定位。
4. 根据结果选择临床评价型、方法创新型或物理成像型论文路线。

项目应坚持一条底线：模型输出是候选筛查结果，不是临床诊断；创新宣称必须由可复现实验和系统查新共同支撑。
