 # 基于深度学习的口腔荧光图像辅助诊断研究——文献综述报告
 
 ## 1 研究背景与临床需求
 
 口腔癌是全球范围内发病率和死亡率较高的恶性肿瘤之一。据GLOBOCAN 2022统计数据，全球每年新发口腔癌病例超过35万例，且发病率呈上升趋势[Bray, 2024]。口腔鳞状细胞癌（OSCC）是最常见的口腔恶性肿瘤，其早期诊断对提高患者生存率至关重要——早期发现的口腔癌5年生存率可达80%以上，而晚期发现则降至20%以下。然而，传统诊断方法如临床视诊、触诊以及CT、MRI等影像学检查，在面对微小或表浅病变时存在明显局限[Zhao, 2025]。
 
 口腔潜在恶性疾病（OPMDs）包括白斑（Leukoplakia）、红斑（Erythroplakia）、口腔扁平苔藓（OLP）等，这些病变具有一定的恶变风险，需要定期监测和及时干预。然而，OPMDs的早期表现往往不典型，依赖于临床医生的经验和主观判断，容易出现误诊和漏诊[Baldi, 2026]。因此，开发一种客观、标准化、可量化的辅助诊断工具具有重要的临床意义。
 
 ## 2 口腔荧光成像技术的研究进展
 
 ### 2.1 自发荧光成像原理与技术优势
 
 自发荧光成像（Autofluorescence Imaging, AFI）是一种非侵入性的光学成像技术，通过特定波长的激发光照射组织，使组织内源性荧光团（如胶原蛋白、弹性蛋白、NADH、FAD等）发出荧光信号。正常黏膜组织与病变组织由于代谢状态、组织结构不同，其荧光发射特性存在显著差异，从而实现病变区域的对比增强。
 
 Cherry等[2019]使用405nm LED激发光源对口腔OPMDs患者进行自发荧光成像，通过计算红绿像素强度比（RG Ratio）对荧光图像进行定量分析，发现AFI定量参数能够有效区分进展型和非进展型病变。该研究对133次临床随访的自发荧光图像进行了分析，结果显示AFI监测结果与临床专家判断具有良好的一致性，证明AFI有潜力辅助临床医生进行非侵入性的口腔癌前病变监测。
 
 ### 2.2 多模态光学成像系统
 
 单一模态的光学成像往往难以同时获得高敏感度和高特异度。Yang等[2019]开发了一套集成了白光成像（WL）、自发荧光成像（AF）和高分辨率显微内镜（HRME）的多模态光学成像系统（MMIS），并配备了实时图像分析算法。该系统使用405nm LED激发自发荧光，通过USB连接至触控笔记本电脑，构建成本约3000美元，具有良好的可及性。系统能够生成热力图勾勒可疑病变区域，并实时预测病理诊断，成功实现了对临床可疑但实际为良性的OPLs避免不必要的活检。
 
 在荧光深度信息获取方面，Kurosawa等[2025]将空间频域成像（SFDI）与深度学习相结合，开发了能够量化荧光包裹体亚表面深度的系统。该系统基于扩散理论的数值模拟生成合成图像进行深度学习训练，使用ResNet和U-Net卷积神经网络预测荧光边缘距离和荧光团浓度。在口腔癌光学特性条件下，U-Net模型对最近深度的预测误差仅为0.33±0.31mm（硅胶模型），在PpIX荧光体模中误差为0.57±0.38mm。该研究展示了荧光成像从二维定性分析向三维定量评估发展的技术潜力。
 
 ## 3 深度学习在口腔病变诊断中的应用
 
 ### 3.1 基于深度学习的口腔病变分类
 
 深度学习技术在医学图像分析领域取得了突破性进展。在口腔病变诊断方面，Figueroa等[2022]提出了基于引导注意力推理网络（GAIN）的可解释深度学习方法。该研究以VGG19为骨干网络，采用两阶段训练策略，结合Grad-CAM实现可解释性，并在印度三个临床中心采集的口腔图像上进行了验证。在二分类任务（可疑阳性 vs 非可疑）上，GAIN训练后的网络在测试集上达到了84.84%的准确率，敏感度为76.6%，特异度为89.3%，优于传统迁移学习方法。
 
 Kumar等[2026]系统比较了四种卷积神经网络模型——ResNet50、DenseNet201、EfficientNetB0和ConvNeXtTiny——在口腔鳞状细胞癌组织病理学图像二分类中的性能。实验结果表明，EfficientNetB0以97.6%的准确率和0.9963的ROC-AUC得分取得了最优表现，显著优于ResNet50的71.52%和DenseNet201的86.08%。这一结果验证了EfficientNet系列由于其复合缩放策略在参数效率和性能之间取得了最佳平衡。
 
 ### 3.2 目标检测与语义分割
 
 除图像级分类外，目标检测和语义分割在口腔病变分析中也显示出重要价值。Baldi等[2026]利用YOLOv8实例分割架构，在583张临床口内图像上实现了口腔潜在恶性疾病和口腔癌的检测与分类。经过数据增强后，该模型在mAP@50指标上达到98.83%，精确度为96.76%，召回率为98.24%，展现了目标检测框架在口腔病变筛查中的巨大潜力。

Tanriver等[2021]利用深度学习卷积神经网络对口腔临床图像进行自动检测和分类，专门针对口腔潜在恶性疾病（OPMDs）的识别。该研究证实了深度学习方法在口腔病变分类任务中的可行性，为本项目的基线方法选择提供了参考依据。
 
 Song等[2022]提出了基于贝叶斯深度学习的UNet模型用于口腔癌图像的语义分割，能够量化预测中的不确定性。通过去除不确定像素，模型的像素精度和平均交并比得到了进一步提升。该研究还开发了高效模型，使推理速度提高了约2倍，模型体积缩小了6倍，为在资源有限环境中部署便携式诊断设备提供了技术基础。
 
 ## 4 深度学习模型的可解释性研究
 
 深度学习模型在医学诊断中的应用面临一个关键挑战——缺乏可解释性。临床医生难以信任一个"黑箱"模型的诊断结果，尤其是在涉及患者生命的医疗决策中。
 
 Grad-CAM（Gradient-weighted Class Activation Mapping）是目前最广泛使用的CNN可解释性方法之一，通过计算类别得分相对于特征图的梯度，生成突出显示模型决策依据区域的注意力热力图[Figueroa, 2022]。在口腔癌分类任务中，Grad-CAM能够可视化模型关注的病变区域，帮助临床医生理解模型决策的合理性。
 
 Song等[2023]在此基础上进一步提出了注意力分支网络（Attention Branch Network, ABN），将视觉解释与注意力机制有机结合。该研究以ResNet18为骨干网络，通过引入Squeeze-and-Excitation（SE）模块进一步提升性能，并创新性地引入了人类在环（Human-in-the-loop, HITL）深度学习方法——通过让口腔医学专家手动编辑注意力图，将专家知识直接嵌入网络训练过程。实验结果表明，ABN使交叉验证准确率从基线的84.6%提升至87.5%，加入SE模块后达到87.7%，而嵌入专家知识后进一步达到90.3%。这一结果表明，将人类临床知识融入深度学习模型不仅能提升可解释性，还能显著改善分类性能，为构建临床可信的口腔癌辅助诊断系统提供了新的方法论框架。

在Grad-CAM的基础上，Figueroa等[2022]采用了GAIN架构，将可解释性从事后分析提升为主动训练目标。GAIN包含三个训练流：分类流、注意力挖掘流和边界框流，通过联合优化，使模型的注意力更精确地聚焦于病变区域。实验结果表明，GAIN训练的注意力图能够更完整、更准确地勾勒病变边界，甚至优于原始标注的边界框。这一方法为构建临床可信的AI辅助诊断系统提供了重要的方法论指导。
 
 此外，Song等[2022]从另一个角度切入可解释性问题——不确定性量化。通过贝叶斯深度学习方法和Monte Carlo Dropout，模型能够为每个预测像素提供不确定性估计，从而提示临床医生哪些区域的预测结果需要进一步审慎评估。
 
 ## 5 AI辅助内镜诊断综述
 
 Zhao等[2025]系统综述了人工智能辅助内镜在早期口腔病变诊断中的应用。该综述涵盖了白光成像、窄带成像（NBI）和自发荧光成像等多种内镜技术，以及Mask R-CNN、U-Net等深度学习方法在病变检测、分割和分类中的应用。综述指出，尽管AI辅助内镜展现出广阔前景，但仍面临标准化数据集缺乏、预处理方法不统一、模型过拟合等挑战。迁移学习、数据增强和多任务学习是当前应对这些挑战的主要技术手段。同时，伦理问题、数据隐私和临床验证需求仍是AI技术落地的重要障碍。
 
 ## 6 本项目的技术路线

基于上述文献分析和临床需求，本项目拟采用以下技术路线：

在数据层面，项目使用的口腔荧光图像数据集由北京大学口腔医院提供，图像为405nm激发光下采集的自发荧光照片。数据集包含589张JPEG格式图像，其中510张配有PASCAL VOC格式的XML标注文件，标注了病变区域边界框及类别信息。数据按患者来源组织，涵盖多种口腔黏膜病变类型。

在模型层面，考虑到标注数据为目标检测格式，本项目拟采用YOLOv8系列算法作为基线模型。YOLOv8继承了YOLO系列模型在实时性和检测精度方面的优势，并在实例分割任务上表现出色[Baldi, 2026]。通过对预训练权重进行迁移学习微调，使其适应口腔荧光图像的特征分布。训练策略方面，将采用余弦退火学习率调度、数据增强（Mosaic、MixUp等）以及早停机制，以提升模型的泛化能力和训练效率。

在评估层面，本项目将采用mAP@50、mAP@50-95、精确度（Precision）和召回率（Recall）作为主要评价指标，与现有文献中的基线方法进行对比分析。同时通过混淆矩阵分析模型对不同类型病变的识别能力。

在可解释性层面，参照Figueroa等[2022]的方法，在训练完成后对模型的检测结果进行Grad-CAM可视化分析，生成注意力热力图，展示模型做出检测决策时所依据的图像区域。这不仅有助于验证模型是否关注了正确的病变区域，也为临床医生理解和信任AI诊断结果提供了直观依据。

此外，项目还将开发一个基于Gradio的轻量级演示原型系统，支持用户上传口腔荧光图像并实时获取检测结果和可视化解释，为后续的临床应用验证奠定基础。

## 7 研究空白与项目定位

通过上述文献梳理可以发现，当前口腔病变AI诊断领域存在以下研究空白：

第一，目前大多数研究使用普通白光口内图像或组织病理学图像，专门针对口腔自发荧光图像的深度学习研究相对较少。荧光图像具有独特的色彩特征和对比度特性，有望获得优于白光图像的诊断性能。

第二，现有研究多为二分类任务（病变 vs 正常），缺乏对多种口腔黏膜病变类型的精细化分类研究。临床上不同病变类型的治疗方案差异显著，精细化分类更具实用价值。

第三，将可解释性方法（如Grad-CAM）系统性地融入口腔荧光图像分析的研究尚不充分，尤其是在荧光图像特有的色彩信息与深度学习特征提取的结合方面。

第四，目前基于YOLO系列模型在荧光图像上的应用研究极为有限，多数检测研究仍集中在普通白光图像上，荧光图像在目标检测任务中的特性尚未被充分挖掘。

基于以上分析，本项目定位于：利用北京大学口腔医院提供的临床口腔荧光图像数据集，采用YOLOv8深度学习目标检测方法，实现口腔黏膜病变的自动检测与分类，并结合Grad-CAM可解释性技术提供可视化的诊断依据。预期成果包括一篇学术论文、一个可演示的软件原型系统以及完整的项目研究报告，项目周期为2026年7月至2027年5月。
