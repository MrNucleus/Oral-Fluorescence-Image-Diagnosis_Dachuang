# 模型优化构想与创新点对应关系

> 文件性质：优化阶段设计草案，不是已完成的实验结果。  
> 数据口径：沿用 `oral_binary_v5_yolo_2026-10-18_v1` 的冻结划分；不由测试集反向选择模型。

## 1. 优化起点

现有两个整图基线提供的信号并不一致：

| 模型 | 验证 AUROC | 测试 AUROC | 测试敏感度 | 测试特异度 | 主要问题 |
|---|---:|---:|---:|---:|---|
| ResNet18 | 0.8743 | 0.7988 | 0.9855 | 0.3488 | 几乎倾向全部判为病变候选，假阳性高 |
| ResNet50 | 0.9279 | 0.6943 | 0.7971 | 0.5814 | 验证到测试落差大，整体排序能力不足 |

因此，优化目标不应只写成“提高准确率”，而应同时回答三个问题：

1. 模型是否能在同一来源组的多次拍摄中稳定识别病变候选证据。
2. 在白光、荧光或缺失一种模态时，模型是否仍能保持可用性能。
3. 模型能否给出经过校准的风险，并在低质量或高不确定时不强行判断。

这三项分别对应组级决策、模态适应和可信筛查，也是项目创新性的主要落点。

## 2. 总体技术路线

建议把优化主线命名为：

> 模态感知的来源组级多示例可信筛查

其核心不是再叠加一个通用注意力模块，而是改变模型的输入组织和输出方式：

- 输入单位从“一张图片”扩展为“同一来源组的多张图片”。
- 输入假设从“固定双模态配对”改为“允许白光、荧光或缺失模态”。
- 输出从单一类别概率扩展为组级概率、不确定性和是否弃权。
- 图像质量作为可靠性信号参与聚合，而不是只做统一预处理。

### 2.1 推荐主架构

```text
组内图片
  -> 共享图像编码器（EfficientNet-B3 / ResNet50 / DenseNet121）
  -> 图像特征 + 模态嵌入 + 可选质量特征
  -> 来源组内注意力聚合
  -> 组级病变候选概率与不确定性
  -> 校准、阈值和可弃权输出
```

训练时以 `group_id` 组织 bag，类别标签仍使用来源组的候选标签。正组中并非每张图片都一定含病灶，因此允许模型通过注意力选择支持阳性的图片。该思路对应现有创新清单中的组级多示例学习（I01）和组级决策聚合（I27）。

### 2.2 聚合方式

先保留最简单的可解释基线，再比较：

1. 图像概率均值。
2. 图像概率最大值。
3. 质量加权均值。
4. 模态感知注意力池化。
5. 带不确定性惩罚的注意力池化。

注意力权重可写成：

```text
alpha_i = softmax(w · [f_i, m_i, q_i])
z_g = sum_i alpha_i * f_i
p_g = sigmoid(classifier(z_g))
```

其中 `f_i` 是图像特征，`m_i` 是模态嵌入，`q_i` 是质量特征。主创新点是“组内、多模态、质量感知的聚合”，而不是普通 CBAM/SE 模块本身。

## 3. 架构对比

### 3.1 EfficientNet-B3

- 作为主优化候选，参数量和表达能力介于 ResNet50 与更重模型之间。
- 与 ResNet50 使用同一数据、split、输入尺寸、增强和选模规则。
- 第一轮只换编码器，不加入复杂模块，确认架构本身是否带来稳定增益。

### 3.2 DenseNet-121

- 作为结构对照，检验特征复用和密集连接是否更适合细粒度黏膜纹理。
- 不把 DenseNet 本身写成创新，只作为模型选择的证据。
- 若显存不足，优先调整 batch 或使用梯度累积，不改变评价集。

### 3.3 ResNet50

- 保留为正式基线，所有后续模块必须在同一基线上做消融。
- 新模块只有在验证集和来源组级评价中稳定优于该基线，才进入报告主结果。

## 4. 注意力机制如何设计

### 4.1 不建议作为主创新的方案

- 仅在 ResNet 中插入 SE、CBAM 或普通自注意力层。
- 只凭测试集指标证明注意力模块有效。
- 把注意力热图直接解释为病灶定位，而不与历史框或人工区域核验。

这些方案可以作为图像编码器内部的消融项，但不足以支撑独立创新。

### 4.2 建议作为主创新的方案

采用“模态感知组级注意力”：

- 同一来源组的不同图片共享编码器。
- 模态嵌入让模型区分白光和荧光。
- 质量向量参与权重计算，低质量图片可被降权但不能被直接删除。
- 输出图片级注意力分布，用于解释组级判断依赖哪些图片。
- 通过模态 dropout 训练，使模型在缺少一种模态时仍能聚合。

这一设计同时连接 I01 组级多示例学习、I02 缺失模态鲁棒学习、I06 模态条件归一化和 I10 质量感知可弃权预测。

## 5. 损失函数实验

损失函数本身不构成主创新，但可以用于改善当前假阳性和概率可靠性。建议按以下顺序比较：

| 方案 | 目的 | 主要风险 |
|---|---|---|
| 普通交叉熵 | 保持基线 | 对少数类和困难样本关注不足 |
| 类别加权交叉熵 | 改善正常/病变候选不平衡 | 可能提高敏感度但降低特异度，需在验证集确认 |
| 标签平滑交叉熵 | 降低候选标签噪声导致的过度自信 | 可能削弱高置信边界 |
| Focal Loss | 聚焦困难样本 | 小数据集上容易放大噪声 |

所有类别权重只能由训练集计算，阈值和校准参数只能由验证集确定。测试集不参与损失函数或超参数选择。

在完成单图损失消融后，再加入两条与创新相关的约束：

- **模态一致性损失**：同一组在完整模态和随机屏蔽一种模态后的组级预测应保持接近。
- **组级对比约束**：同组不同图片的表征应比不同组更接近，但不假设白光与荧光对应同一病灶位置。

第二条约束只有在组内同时存在两种模态时启用，属于探索性 P1，不与主架构同时上线。

## 6. 实验阶梯

### 阶段 A：编码器筛选

- EfficientNet-B3、DenseNet-121、ResNet50。
- 相同 split、640 输入、geometry 增强、验证集交叉熵选模。
- 单图评价 + 来源组聚合评价。
- 先单随机种子筛选，保留表现稳定的两个模型。

### 阶段 B：损失函数消融

- 普通 CE、类别加权 CE、标签平滑 CE、Focal Loss。
- 以组级 AUROC、固定敏感度下特异度、Brier/ECE 和校准曲线共同比较。
- 不按测试集挑选损失函数。

### 阶段 C：组级聚合

- 均值、最大值、质量加权均值、模态注意力、注意力加不确定性惩罚。
- 主指标为组级 AUROC、组级敏感度/特异度、校准和固定覆盖率下的漏诊率。
- 同时报告每组的图片数、模态数和质量分布，检查聚合是否被单张高质量图片主导。

### 阶段 D：缺失模态与质量门控

- 完整双模态、仅白光、仅荧光、随机缺失。
- 训练时进行模态 dropout。
- 按清晰度、曝光、高光比例等质量指标分层报告。
- 预注册风险—覆盖率曲线和弃权规则。

### 阶段 E：解释与最终验证

- 对冻结候选模型生成 Grad-CAM。
- 使用历史 XML 框只做解释定位审计，不把它作为训练输入。
- 在新的独立保留集或外部队列上进行最终评价。

## 7. 与创新点的对应关系

| 优化内容 | 对应创新点 | 创新层级 | 说明 |
|---|---|---|---|
| ResNet50 与 EfficientNet-B3/DenseNet121 控制变量比较 | 可复现实验基准 | 工程与评价基础 | 架构替换本身不作为主创新 |
| 来源组 bag 与注意力聚合 | I01、I27 | 主方法创新 | 从单图判断转为来源组级决策 |
| 模态嵌入与缺失模态训练 | I02、I06 | 主方法创新 | 处理非配对、多变模态输入 |
| 质量特征参与聚合和弃权 | I10、I21、I23 | 可靠性创新 | 将质量作为模型输入而非仅做预处理 |
| 组级非配对跨模态对齐 | I03、I04 | 二级方法创新 | 只有在主基线稳定后再验证 |
| 类别加权、标签平滑、Focal Loss | 校准与鲁棒性支撑 | 消融项 | 不单独包装为主创新 |
| Grad-CAM 与 XML 定位审计 | I26 | 可解释性贡献 | 框只用于评价，不参与训练 |
| 部位分层与辅助任务 | I07、I25 | 评价与领域适配 | 部位是分层/辅助信息，不是疾病标签 |

## 8. 评价口径

模型优化阶段必须同时报告以下四类结果：

1. **总体层面**：图像级和来源组级 AUROC、敏感度、特异度、平衡准确率、混淆矩阵。
2. **可靠性层面**：Brier score、ECE、风险—覆盖率曲线、弃权比例和高置信区间性能。
3. **分层层面**：模态、部位、质量等级和图片数量分层；子组过小标为描述性结果。
4. **稳定性层面**：多个随机种子、训练集内来源组交叉验证、按来源组聚类的置信区间。

当前来源组数多于测试来源组数，测试子组样本很小，因此不能把一次测试的局部提升写成稳定创新。最终论文主结果应来自预先冻结的独立评价，而不是对已有测试集的反复尝试。

## 9. 决策规则

- 如果组级 AUROC 持续低于约 0.65，且多种子与组级交叉验证不稳定，停止继续堆叠模块，转向标签复核、数据质量和成像物理研究。
- 如果组级 AUROC 约在 0.65 至 0.75，优先完成校准、弃权、模态和部位分层，形成“可靠性优先”的论文路线。
- 如果组级 AUROC 稳定高于约 0.75，且主要消融有一致增益，推进“缺失模态组级筛查”的方法创新型路线。
- 任何只在测试集表现好、验证集无同向变化或来源组交叉验证不稳定的改进，都不作为主贡献。
- 阴性消融结果必须保留，不能因为不符合预期而删除。

## 10. 推荐执行顺序

1. 先完成 EfficientNet-B3 和 DenseNet-121 的单图基线。
2. 在同一数据与预算下完成损失函数小规模消融。
3. 实现来源组 bag 数据集、均值/最大值/注意力聚合。
4. 比较组级指标，确认组级聚合是否优于单图判断。
5. 加入模态 dropout、质量特征和校准。
6. 最后再尝试非配对跨模态对齐或蒸馏。
7. 冻结候选模型后执行 Grad-CAM 和最终独立验证。

这条路线把“换模型”“做注意力”和“提出创新”分开：编码器和损失函数用于寻找可靠基线，真正的主创新由组级多示例学习、模态适应和质量感知弃权共同构成。
