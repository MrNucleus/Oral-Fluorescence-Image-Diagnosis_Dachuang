# 正确标签下的 EfficientNet-B3 40轮训练

## 1. 目的与数据口径

本轮使用修正后的 `binary_annotated_v2` 清单，标签固定为：

- `n` = 阴性病例，编码0
- `l` = 阳性病例，编码1

只使用有有效框的图片，共509张；训练、验证、测试为339/88/82张，对应57/13/13位患者。

## 2. 训练配置

- 模型：ImageNet预训练 EfficientNet-B3
- 优化器：Adam
- 总上限：40 epoch
- 阶段比例：8/16/16，对应指导书20:40:40
- 学习率：1e-3 / 1e-4 / 1e-5
- Dropout：0.5
- Label smoothing：0.1
- Weight decay：1e-4
- 早停：每个阶段patience 10
- 最优模型：验证集准确率；同分比较macro F1和AUROC
- 训练环境：PyCharm Run，实时HTML看板

## 3. 实际训练

实际完成35个epoch：

| 阶段 | 解冻范围 | 实际epoch |
|---|---|---:|
| 1 | 只训练分类头 | 8 |
| 2 | 最后两个stage | 11，早停 |
| 3 | 全部参数 | 16 |

最佳检查点来自阶段1第5个epoch。

## 4. 验证集结果

| 指标 | 数值 |
|---|---:|
| Accuracy | 0.7045 |
| Balanced Accuracy | 0.6954 |
| Macro F1 | 0.6848 |
| AUROC | 0.7011 |
| Sensitivity | 0.7241 |
| Specificity | 0.6667 |
| Kappa | 0.3728 |

## 5. 测试集结果

| 口径 | Accuracy | Balanced Acc | AUROC |
|---|---:|---:|---:|
| 图像级 | 0.5244 | 0.5568 | 0.5874 |
| 患者级 | 0.6923 | 0.7083 | 0.6667 |

患者级敏感度0.6667，特异度0.75。

## 6. 结论

1. 正确标签下的训练流程已经完整跑通，训练、验证、测试和最优检查点文件齐全。
2. 最佳模型仍停留在阶段1，说明后续解冻带来的训练集拟合没有转化为验证集改善。
3. 验证集与测试集患者级AUROC分别为0.7011和0.6667，仍不足以支持论文主结论。
4. 图像级测试AUROC仅0.5874，说明图像级泛化仍然较弱。
5. 后续应重复患者级切分，检查阈值和置信区间，并优先解决标签噪声和数据版本问题。
